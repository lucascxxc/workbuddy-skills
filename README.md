# workbuddy-skills

两个做成 WorkBuddy Skill 的可复用流程。

Skill 和普通脚本的区别：它带**触发条件**和**执行约束**，
说一句话就能跑，且约束是代码级的、违反不了。

---

## 1. weekly-report — 团队周报 PPT

每周一份约 30 页的 PPT，8 步跑完。

```
复制上周 PPT → 更新封面与 WK 编号 → 填计划组项目表 → 更新仪表盘
→ 更新资金/物资 → 填科研组 → 填质量/运维组 → 格式校对
```

**输入**：上周已完成周报 PPT + 本周新增素材（Excel / doc / 文本）
**输出**：新一周完整 PPT

### 三条铁律

1. 同项目按编号匹配更新，不新建
2. 本周没提到的内容，原样保留
3. 图表、版式、字体、涉密内容一律不动

约束写进代码，不是写在文档里让人记。

### 三份参考文档

| 文档 | 内容 |
|---|---|
| `references/ppt_structure.md` | 30 页完整版式：标题、表格结构、图表位置、形状定位、页面复制规则 |
| `references/excel_mapping.md` | 输入文件 → PPT 页映射：项目表列映射、中心分组、资金/物资列、台账汇总口径 |
| `references/format_rules.md` | 三条铁律、字体体系、编号与日期规则、表格操作规范、交付检查清单 |

这三份才是真正的资产——代码能重写，这些细节丢一次就得重新翻 PPT 数一遍。

### 项目表双模式

项目表有 10 列和 12 列两种版本，警示灯列索引不同。
做法是**先数列数再决定字段位置**，不写死索引。

## 2. golden-quote-sketch-html — 金句手绘长图

把长文、访谈、播客稿做成「金句 + 手绘 + 解读」风格的单文件 HTML 长图，
可再导出成一张竖向长图。

流程：提炼金句 → 生成手绘配图 → 压缩 → base64 内联 → 拼接长图。

| 脚本 | 职责 |
|---|---|
| `scripts/build_html.py` | 组装 HTML |
| `scripts/compose_longimage.py` | 拼竖向长图 |
| `scripts/make_cover.py` | 生成封面 |

---

## 怎么用

把整个目录放到 WorkBuddy 的 skills 目录下：

```
~/.workbuddy/skills/weekly-report/
```

触发方式是说人话，比如「做周报」「更新周报」。

---

## 关于涉密

Skill 本身不含任何业务数据。铁律第三条明确：涉密内容不进流程、不落文件。
