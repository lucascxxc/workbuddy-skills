| 文件 | 用途 | 对应 PPT 页 |
|---|---|---|
| `WK{编号}周报填写.xlsx` | 计划组全部数据 | P2-P17 |
| `政策性课题、项目申报台账.xlsx` | 科研组工作内容表 + 统计行 | P19-25 |
| `每周更新.xlsx` | 科研组每周更新表 | P18 |

## 一、《周报填写.xlsx》 — 项目进度成本表

**sheet 名**：`WK{编号}项目进度成本表`（按文件名实际 sheet 名匹配，通常是第一个带"项目进度成本表"的 sheet）

### 行结构
- R1：提示语（跳过）
- R2：表头
- R3 起：数据行（一个中心一组，序号每组从 1 开始；可能有跳号）

### 列映射（1-based，A=1）

| Excel 列 | 表头 | 填入 PPT 表格列 |
|---|---|---|
| A (1) | 序号 | 序号（按中心重排，见下） |
| B (2) | 所属/中心 | 所属中心 |
| C (3) | 项目编号 | 项目编号（匹配主键） |
| D (4) | 项目名称 | 项目名称 |
| E (5) | 负责人 | 负责人 |
| F (6) | 项目当前阶段（下拉选择） | 项目当前阶段 |
| G (7) | 预计工时 | 预计工时（原样文本，含"变更为"等说明） |
| H (8) | worktile已填报工时 | 已填报工时（数值，可保留小数或取整） |
| I (9) | 本周进展、风险、待协调事宜 | 本周进展、风险、待协调事宜 |
| J (10) | 最近节点 | 最近节点（datetime 转 `YYYY/M/D`） |
| K (11) | 警示灯 | 警示灯（红/黄/绿，也用于仪表盘统计） |
| L (12) | 已实施时长/（月） | 开工月数 |
| W (23) | 自研 | **筛选键**：`是` → 自研项目页；其他 → 按 B 列所属中心入对应中心页 |
| AA (27) | 成本变更 | 不填 PPT（辅助参考） |
| AB (28) | 暂停 | 不填 PPT（辅助判断） |

### 中心分组（B 列取值 → PPT 页面标题）
- `立方星项目办` → `立方星项目办项目进度`
- `通信星项目办` → `通信星项目办项目进度`
- `灵鹊星通` → `灵鹊星通项目进度`
- `卫星工程中心` → `工程中心项目进度`
- `卫星数据中心` → `数据中心项目进度`
- `卫星研发中心` → `研发中心项目进度`
- `卫星应用中心` → `应用中心项目进度`
- `遥感星项目办` → 若存在则建 `遥感星项目办项目进度` 页（WK34 中遥感星项目归入自研页；单独项目出现时新增页面）
- 其他未知中心 → 报告用户，暂不加入

### 项目更新三规则（核心逻辑）
1. **同项目更新**：项目编号（C 列）与上周 PPT 中已有编号匹配 → 用本周 Excel 数据**替换**该行内容（阶段/工时/进展/节点/警示灯/月数）
2. **新增项目**：编号不在上周 PPT：
   - 进展列（I）非空且非"无" → 加入对应页（自研页全局序号续排；中心页序号重排）
   - 进展为空或"无" → 暂不加入，在交付报告中列出"低活跃未加入清单"提示用户
3. **保留项目**：上周 PPT 有、本周 Excel 没有 → **保留不动**（用户规则："没提及的先保留"）

### 序号重排规则
- 自研项目页：全局连续 1..N
- 各中心页：按中心内连续 1..N（重新编号，不沿用 Excel 序号）
- 每页数据行 ≤ 6，超过则复制模板页追加

## 二、《周报填写.xlsx》 — 资金计划表

**sheet 名**：`WK{编号}资金计划表`

- R1 标题、R2 表头、R3 起数据、最后一行是 `=SUM(...)` 合计公式行
- **数据可能为空**（如 WK34 版 R3-R7 为空）→ 此时**保留上周 PPT 内容不动**
- 非空时替换 PPT P16 数据行，并更新合计行金额

### 列映射（Excel 列 → PPT 10 列）
| Excel 列 | 表头 | PPT 列 |
|---|---|---|
| A | 序号 | 序号 |
| B | 反馈日期 | 反馈日期 |
| C | 所属中心 | 所属中心 |
| D | 项目名称 | 项目名称 |
| E | 收款方 | 收款方 |
| F | 金额/元 | 金额/元 |
| G | 发票 | （PPT 无此列，跳过） |
| H | 到票金额 | （PPT 无此列，跳过） |
| I | 建议支付节点 | 建议支付节点（注意 Excel 顺序） |
| J | 优先级 | 优先级 |
| K | 状态 | 状态 |
| L | 备注 | 备注 |

注意：Excel 列顺序（发票/到票金额在中间）与 PPT 不同，**按表头名映射而非列顺序**。

## 五、《政策性课题、项目申报台账.xlsx》

**sheet**：Sheet1
- R1 标题、R2 **汇总统计**、R3 表头、R4 起数据（含子行）

### 汇总统计（R2）→ P19 顶部文本框
源格式：`成功：3项；  未成功：4项； 不符合条件：14项；  评审阶段：9项；  材料准备中：1项；  预埋指南：3项；  入围决赛准备中：3项；  论证中：0项`

目标格式：`共37项机会：申报后评审成功【3项】；申报后未成功【4项】；不符合申报条件【14项】；申报完成评审进行中【9项】；材料准备中【1项】；预埋指南【3项】；入围决赛准备中【3项】`

映射：成功→申报后评审成功、未成功→申报后未成功、不符合条件→不符合申报条件、评审阶段→申报完成评审进行中、材料准备中/预埋指南/入围决赛准备中 同义直转；"共计N项"→`共N项机会`；论证中 0 项不显示。**涉密内容"（涉M不具体说明）"照搬不改**。

### 数据行 → P19-25 工作内容表（9 列）
- 表头：`序号 | 申报题目 | 通知文件 | 送交单位 | 申报主体 | 技术负责人 | 财务预算编制 | 报送日期 | 进展/官方反馈`
- 列顺序与 Excel 一致（A 序号、B 申报题目、C 通知文件、D 送交单位、E 申报主体、F 技术负责人、G 财务预算编制、H 报送日期、I 进展/官方反馈）
- **子行**：序号（A 列）为空的续行属于上一主行（如"无人/反无人平台协同管理软件"），必须紧跟主行，更新/分页时不可拆散
- 分页：沿用上周 PPT 的条目分布；条目增/减时从最后一页调整（增则复制页模板，减则删行）
- 更新方式：按序号逐条替换对应行文本（上周 PPT 有 1-37 条）

## 六、《科研组周报{日期}.doc》

Word 97-2003 老格式（olefile 提取）。文本结构为连续条目，每条含三要素：
```
{工作内容标题}
{进度情况正文}
推进方向：
{推进方向内容}
```
→ 填入 P26-27 推进方向表（4 列：序号|工作内容|进度情况|推进方向/亟待解决）

- 更新策略：按"工作内容"标题匹配上周 PPT 已有行 → 替换；新条目 → 追加（排最后）
- WK34 的 5 条顺序：1 商业航天储备课题、2 慧眼行动（涉军涉密）、3 频轨资源、4 协助投标、5 知识产权
