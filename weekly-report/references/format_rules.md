# 格式细则（format_rules.md）

## 三条铁律（任何时候不违反）

1. **同项目更新、新项目加入、未提及保留**：按项目编号匹配替换；上周 PPT 有而本周未提及的项目**保留不动**；只有"相同类型的工作内容"才用新内容替换旧内容
2. **图表与版式不动**：图表类型、series 名称、颜色方案、字体体系、页面版式、设计元素一律保持旧版不变，只换数据/文本
3. **涉密内容照搬**：`（涉密不具体说明）`、`（涉M不具体说明）`、`（涉军涉密）`、`军方项目` 等字样原样保留，不展开、不修改、不删减

## 字体体系

| 位置 | 字体 | 规格 |
|---|---|---|
| 页面顶部标题（TextBox 42） | 微软雅黑 | 加粗，run2 分隔符 `— ` 蓝色 006AB7，其余背景色 |
| 12 列项目表 | 随模板（微软雅黑系列） | 表头加粗，数据行普通 |
| 质量组正文 | 仿宋 | 16pt 加粗，两端对齐 |
| 运维组正文 | 微软雅黑 | 12pt，颜色 ACCENT_1 蓝，加粗 |
| 科研组统计行 | 微软雅黑 | 14pt，分类名带色（评审成功 FF0000 等） |

更新表格/文本框文本时**必须保留原有 run 的字体格式**：不直接 `cell.text = ...`（会丢格式），而是修改第一个 run 的 `.text` 并删除其余 run，或逐 run 对应替换（统计行数字 run）。

## 编号与日期

- 周编号：每周 +1（WK34 → WK35）
- 封面日期：`M/D-M/D`（如 `8/14-8/21` → `8/21-8/28`），按每周五到下周五的惯例（上一周期末 = 本周期初）
- 文件名：`WK35每周重要信息公示栏(0821-0828).pptx`（括号内为月日区间，无年份）
- Excel 日期时间（datetime）→ PPT 文本 `YYYY/M/D`（如 `2026/10/31`）

## 表格操作规范

- **改文本保格式**：单元格内保留第一个段落的第一个 run，改其 text，删除多余 run 和多余段落
- **行数增减**：
  - 增加：复制最后一行数据行的 tr 元素（继承格式），插入表格末尾
  - 减少：删除末尾多余数据行（tr 元素）
  - 调整表格高度与行高使排版紧凑（参考同页其他表）
- **行高与分页**：12 列项目表每页最多 6 行数据；科研工作内容表每页最多 8 行（含子行），且**主行+子行不可拆页**
- 空单元格：置空文本（删除 run 文本，不新增）

## 仪表盘统计口径

- 范围 = 更新后实际进入 PPT 的活跃项目
- 红/黄/绿 = 警示灯列统计
- 中心顺序固定：立方星项目办 / 灵鹊星通 / 通信星项目办 / 卫星工程中心 / 卫星数据中心 / 卫星研发中心 / 卫星应用中心 / 遥感星项目办（无项目中心显示 0/空）
- 红牌百分比 = 红 / 总计（四舍五入整数百分比，如 13%）
- P2 顶部总数 = 全部活跃项目数；椭圆数字 = 绿/黄/红合计
- 图表更新：COLUMN_CLUSTERED 的 plot0 四个 series（红黄绿总计）+ plot1 红牌百分比；categories 与 values 用 `chart.replace_data` 或 XML 更新，样式不动

## 质量组/运维组录入

- 用户提供的是纯文本/条目 → 按旧页格式组织：
  - 质量组：`1.标题：` 加粗 + 正文缩进，保留"详见下表"等衔接语，正文与跟踪表数据对应
  - 运维组：`1.描述` 连续编号，微软雅黑 12pt 蓝
- 条目数增减 → 增删段落，编号重排

## 交付清单（每次做完周报必须检查）

1. 封面日期、每页 WK 编号已更新
2. 计划组项目与 Excel 一致（自研/中心归属正确、序号重排、无遗漏）
3. 仪表盘数字、图表、统计表与项目表一致（总数 = 各中心合计 = 红+黄+绿）
4. 资金/物资表（有数据才更新，合计正确）
5. 科研组三张表 + 统计行 + 成果图已更新，子行未拆散
6. 质量/运维组内容已录入，字体格式正确
7. 新文件输出到桌面（不改动上周文件），并向用户报告"低活跃未加入清单"
