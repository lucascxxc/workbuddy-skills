# 周报 PPT 结构说明书（基于 WK34 版，30 页）

## 全局信息

- 文件命名：`WK{编号}每周重要信息公示栏({开始日期}-{结束日期}).pptx`，例如 `WK35每周重要信息公示栏(0821-0828).pptx`
- 幻灯片尺寸：9144000 x 5143500 EMU（16:9，10" x 5.625"）
- 页数：30 页（项目增多时可增加页）
- 顶部标题栏格式：`{组名} — {页面名}{WK编号}`，由 4 个 run 组成：
  - run1 `计划组 `（加粗，微软雅黑）
  - run2 `— `（加粗，微软雅黑，颜色 006AB7 蓝色）
  - run3 页面名（加粗，微软雅黑，背景色）
  - run4 `WK34` 或 `-WK34`（加粗，微软雅黑，背景色）——仪表盘页是 `-WK34` 带连字符，其余页是 `WK34`
- 标题栏位于每页顶部的组合形状内的 TextBox 42（形状名可能不同，按文本前缀"计划组/科研组/质量组/运维组"识别）

## 12 列项目表结构（P4-15 通用）

表头行：`序号 | 所属中心 | 项目编号 | 项目名称 | 负责人 | 项目当前阶段 | 预计工时 | 已填报工时 | 本周进展、风险、待协调事宜 | 最近节点 | 警示灯 | 开工月数`

- 数据行每页容量：约 5-6 行（表格高度约 200-350pt，行数多时调矮行高）
- 行超 6 条时复制同页模板新增一页
- 表头单元格中"所属/中心"等可能带换行符
- 日期格式：`2026/10/31`（斜杠分隔）；Excel 中的 datetime 需转换
- "已填报工时" Excel 是数值（如 10477），直接转整数或保留原样
- 序号规则：**自研页全局连续 1..N**；**各中心页按中心内从 1 重新编号**
- "接下一页"文本框：当一页数据未完时，右下角绿色小字"接下一页"（可选，自动分页时添加）

## 仪表盘页（P2-P3）

P2 需要更新的元素：
- "文本框 7"：3 个 run 组成 `本周活跃项目总数：` + `30` + `个`（只改中间数字 run）
- "椭圆 8"（绿总数）、"椭圆 13"（黄总数）、"椭圆 20"（红总数）：只改文本
- "图表 2"：COLUMN_CLUSTERED 柱状图
  - plot0 含 4 个 series：`红`、`黄`、`绿`、`总计`（按 8 个中心：立方星项目办/灵鹊星通/通信星项目办/卫星工程中心/卫星数据中心/卫星研发中心/卫星应用中心/遥感星项目办）
  - plot1 含 1 个 series：`红牌百分比`（0-1 小数）
  - 图表类型、series 名称、样式一律不改，只更新 categories 与 values

P3 需要更新的元素：
- "表格 4"：10x6
  - R0 表头：所属中心|红|黄|绿|总计|红牌百分比
  - R1-R8：8 个中心（固定顺序：立方星项目办/灵鹊星通/通信星项目办/卫星工程中心/卫星数据中心/卫星研发中心/卫星应用中心/遥感星项目办）
  - R9：合计行（红黄绿总计、总活跃数；红牌百分比留空）
  - 红牌百分比格式：整数百分比，如 `13%`（=红/总计，四舍五入）

统计口径：**只统计进入 PPT 的项目**（即更新后的活跃项目清单）。红/黄/绿 由"警示灯"列（K 列）决定。

## 资金计划表（P16，10 列）

表头：`序号 | 反馈日期 | 所属中心 | 项目名称 | 收款方 | 金额/元 | 优先级 | 建议支付节点 | 状态 | 备注`

- 数据行后必须保留**合计行**（金额列 = 各金额之和，如 `936070`）
- 金额是数字（如 80000），注意金额格式不带千分位

## 物资计划表（P17，10 列）

表头：`序号 | 反馈日期 | 所属中心 | 项目名称 | 采购需求 | 是否需要采购询价对比 | 建议合同签订节点 | 要求到货节点 | 状态 | 供货周期`

- 无合计行

## 科研组每周更新表（P18，9 列）

表头：`申报题目 | 通知文件题目 | 送交单位 | 技术负责人 | 财政资金补贴力度 | 公司内部技术审核 | 公司内部财务评审 | 报送日期 | 进展/官方反馈`

- **无序号列**（与工作内容表不同）

## 科研组工作内容表（P19-25，9 列）

表头：`序号 | 申报题目 | 通知文件 | 送交单位 | 申报主体 | 技术负责人 | 财务预算编制 | 报送日期 | 进展/官方反馈`

- P19 顶部统计文本框（TextBox 42）：格式为
  `共37项机会：申报后评审成功【3项】；申报后未成功【4项】；不符合申报条件【14项】；申报完成评审进行中【9项】；材料准备中【1项】；预埋指南【3项】；入围决赛准备中【3项】`
  - 多 run 结构，分类名与数字交替，分类名颜色：评审成功=FF0000、未成功=7030A0、不符合=00B0F0、评审进行中=92D050、材料准备中=FFC000、预埋指南=ACCENT6、入围决赛=默认白
  - 更新时只改数字 run 的文本，保留颜色 run 结构
- 台账条目的"子行"结构：同一序号可能占多行（如序号 29 海洋应急 + 子行"无人/反无人平台协同管理软件"），子行序号为空、只填部分列。**分页与更新时子行必须紧跟主行**
- 每页 4-8 行不等（人工分页），自动分页时每页最多 8 行且不拆散主行+子行

## 科研组推进方向表（P26-27，4 列）

表头：`序号 | 工作内容 | 进度情况 | 推进方向/亟待解决`

- 数据来源为科研组周报 doc 或用户文本，条目含"工作内容/进度情况/推进方向"三要素
- 推进方向单元格通常以 `推进方向：` 开头
- WK34 共 5 条：1 商业航天储备课题、2 慧眼行动、3 频轨资源、4 协助投标、5 知识产权（5 在 P27）

## 质量组页（P29）

- 文本框 2：正文风格为仿宋 16pt 加粗、两端对齐，条目格式 `1.标题：` + 缩进正文，数字类信息（日期/人数/批次）单独 run 便于高亮
- "表格 3"：5 列 `序号 | 项目名称 | 问题描述 | 问题原因 | 进度跟踪`

## 运维组页（P30）

- 文本框 1：微软雅黑 12pt、颜色 ACCENT_1（蓝色）、加粗、两端对齐，条目格式 `1.描述`、`2.描述`……连续编号

## 页面复制规则（新增页时）

- 复制最接近的模板页（如应用中心多页则复制 P15 页）
- 新页顶部的 WK 编号同步更新
- 新页表格保留表头行 + 空数据行（行数按需增删）
- 插入位置：紧跟原分组最后一页之后（科研组工作内容表追加在 P25 后，标题相同）
